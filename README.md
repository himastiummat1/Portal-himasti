# HIMASTI Web Portal

Portal digital resmi HIMASTI (Himpunan Mahasiswa Sistem dan Teknologi Informasi).

## Features

- Public information portal
- Member/Kader dashboard
- Letter management
- Event management
- Role & permission system
- Audit log
- Super Admin panel

## Tech Stack

- Laravel
- PHP
- MySQL/PostgreSQL
- Blade
- Tailwind CSS
