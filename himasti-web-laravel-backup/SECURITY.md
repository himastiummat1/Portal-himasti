# Security Policy (Kebijakan Keamanan)
## Supported Versions (Versi yang Didukung)
Gunakan versi aplikasi dan dependensi utama yang saat ini didukung oleh pembaruan keamanan Divisi Teknologi HIMASTI:

| Version | Supported |
| :--- | :--- |
| 1.x (Laravel 11) | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability (Pelaporan Celah Keamanan)
Divisi Teknologi HIMASTI sangat menghargai laporan celah keamanan dari pengurus, kader, maupun pihak eksternal untuk menjaga privasi dan keamanan data keanggotaan.
### Prosedur Pelaporan Celah Keamanan:
1. **Jangan Membuka Public Issue**: Jika Anda menemukan celah keamanan (*vulnerability*), **DILARANG** melaporkannya melalui GitHub Issues publik demi keamanan data organisasi.
2. **Kirim Laporan Private**: Harap laporkan langsung ke Kabid Teknologi HIMASTI melalui email resmi `tekno@himasti.or.id` atau kontak langsung pengurus Divisi IT.
3. **Format Laporan**:
   * Deskripsi celah keamanan.
   * Langkah-langkah untuk mereproduksi celah (*Steps to reproduce*).
   * Potensi dampak (*Impact*) terhadap sistem/data.
### Respon Tim IT:
* Tim IT HIMASTI akan merespon dan memverifikasi laporan dalam kurun waktu **1x24 jam**.
* Pembenahan (*patching*) akan segera dilakukan dan dirilis secepatnya setelah verifikasi berhasil.
